# ATM-Management
🏦 ATM Management System A simple program to simulate ATM operations including user authentication, balance inquiry, cash withdrawal, deposits, and mini-statement generation. Built to demonstrate secure transaction handling and core banking logic using python with oops
✨ Features
- User authentication with PIN verification
- Balance inquiry
- Cash withdrawal and deposit functionality
- Mini-statement generation
- Error handling for invalid inputs and insufficient funds
🎯 Purpose
This project is built to showcase how ATM systems work behind the scenes, focusing on security, reliability, and usability. It can be used as a learning resource for students and developers exploring banking applications or transaction-based systems.
